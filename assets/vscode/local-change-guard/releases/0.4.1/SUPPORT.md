# Support

## Usage questions and defects

For usage questions, reproducible defects or feature requests, contact `oxara.dev@gmail.com`. The source repository is private; public users do not need repository access to request support.

Include the Local Change Guard version, VS Code version, operating system, Git version, and minimal reproduction steps. Redact repository content, credentials, private paths, customer names, and other sensitive information.

## Security and private reports

Follow [SECURITY.md](SECURITY.md) for vulnerabilities. For a report that cannot be shared publicly, contact `oxara.dev@gmail.com`.

Support is provided on a best-effort basis. There is no guaranteed response or resolution time for general issues.
